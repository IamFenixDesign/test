# Stockly

Control de stock con precios de Coto Digital y Carrefour.

## Vercel (recomendado)

Importá el repo en [Vercel](https://vercel.com/new). El endpoint `/api/supers` consulta Coto y Carrefour desde el servidor, igual que `npm run dev`.

Sitio de ejemplo: conectá `IamFenixDesign/test`.

## GitHub Pages

https://iamfenixdesign.github.io/test/

En GitHub: **Settings → Pages → Source: GitHub Actions**.
Ahí no hay servidor: la búsqueda de supermercados usa un fallback en el navegador.
